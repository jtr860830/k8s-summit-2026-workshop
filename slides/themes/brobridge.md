# Brobridge 品牌主題（移植自公司 Marp 模板）

## 調色盤

- 背景（內容頁）：`#faf5f2` 米白
- 背景（封面/章節/示範過場頁）：深色漸層 `linear-gradient(160deg, #17171c 0%, #1d1d24 70%, #26181a 100%)`
- 主文字：`#262626`（深色頁上為 `#ffffff`）
- 品牌紅（accent）：`#c00000`；亮紅 `#d50005`；輔助橘 `#f26b43`
- 弱化字：`#8f8f8f`；深色頁弱化字 `#d9d9d9`
- 代碼區塊：底 `#1b1b20`、框線 `#2c2c34`、字 `#e8e8e8`；語法色沿 GitHub Dark（紅 `#ff7b72`、藍 `#79c0ff`、綠 `#7ee787`、橘 `#ffa657`、紫 `#d2a8ff`）

## 字體

- 顯示與內文：`"PingFang TC", "Noto Sans TC", "Microsoft JhengHei", system-ui, sans-serif`
- 等寬：`"Maple Mono NF CN", "Maple Mono", Consolas, Menlo, monospace`

## 版式

- 內容 padding：120px；標題 800–900 字重；品牌紅只用於強調與標題底線，不大面積鋪色
- 章節頁：深色漸層 + 大號白字 + 紅色 eyebrow
- 頁尾：左側 muted 小字（場次名），右側頁碼
